# Search Out Web App🔍

A customizable new tab page and search enhancement tool designed to improve your browsing experience. Search Out provides a clean interface with quick access to search, bookmarks, and other useful features, aiming to make your online navigation more efficient and personalized. It replaces your default new tab page with a streamlined dashboard. This repo contains the front-end files of SearchOut Web App. If you want to review other SearchOut-related projects, you can go to my GitHub profile.

🚀 **Key Features**

*   **Enhanced Search:** Provides an integrated search bar with autocomplete suggestions to quickly find what you're looking for.
*   **Bookmark Management:** Allows you to easily add, store, and access your favorite websites directly from the new tab page.
*   **Clock Display:** Shows the current time, helping you stay on schedule.
*   **Customizable Options:** Offers a range of settings to personalize your browsing experience (details in dropdown menu).
*   **Keyboard Navigation:** Navigate search suggestions using the keyboard for faster interaction.
*   **Dynamic Autocomplete:** Fetches search suggestions from an external API for real-time assistance.

🛠️ **Tech Stack**

*   **Frontend:**
    *   HTML5
    *   CSS3
    *   JavaScript (ES6+)
    *   jQuery
    *   Bootstrap
    *   Bootstrap Icons (SVG)
*   **Storage:**
    *   Local Storage (for bookmark management)
